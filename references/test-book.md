    fonts = config['fonts']
    return f"""
    html {{
        font-family: {fonts['body']};
        color: {colors['text']};
        background: {colors['page_bg']};
    }}
    """

# 总结与展望

本书验证了 Booksmith v2.0 的全部电子书优化功能。

## 已完成功能

- 页码：`@bottom-center counter(page)`
- 页眉：`@top-center string(chapter-title)`
- A5 页面尺寸与对称页边距
- 目录层次：`.toc-level-1` / `.toc-level-2` + 点引导符
- 紧凑章节页：`min-height: 50vh`
- 深色主题预设：`dark-ebook.yaml`
- 表格自适应：`overflow-x: auto`
- 交叉引用自动链接：`见第X章` → 超链接
